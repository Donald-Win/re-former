# Fonts

`LiberationSans-Regular.ttf` — embedded into every generated PDF (see
`embedAppFont()` in `src/shared/pdfDrawUtils.js`) so macrons (ā ē ī ō ū) and
other non-WinAnsi characters render. Metrics match Helvetica/Arial.
